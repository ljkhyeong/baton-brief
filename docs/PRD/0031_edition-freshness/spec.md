# PRD-0031: 브리프 최신 여부 확인

- 상태: 채택됨
- 결정일: 2026-10-05
- 범위: 저장된 브리프가 지금 다시 만들 내용과 같은지 읽기 전용으로 판정

## 목적

BATON은 선택한 브리프 이후에 전달된 변경이 있는지를 자기 전달 기록으로 안내한다. 추가 전달이 있어도
선정 항목은 같을 수 있으므로 "지금 다시 만들면 내용이 달라지는지"는 BATON만으로 알 수 없다.
BRIEF는 생성 때 저장한 브리프 항목과 현재 점검 항목을 가지고 있다. 같은 선정 규칙으로 현재 항목을 다시
선정해 저장된 항목과 비교한다.

## 조회 계약

`GET /api/v1/workspaces/{workspaceId}/seasons/{seasonId}/editions/{editionId}/freshness`

- 경로의 세 식별자는 UUID다. 형식 오류는 `400 Bad Request`와 PRD-0004의 `ProblemDetail`이다.
- 브리프가 없거나 경로의 작업공간·시즌에 속하지 않으면 존재 여부를 드러내지 않고
  `404 Not Found`와 `ProblemDetail`을 반환한다.

| 필드 | 의미 |
| --- | --- |
| `editionId` | 확인한 브리프 |
| `upToDate` | 같은 주간·시간대로 지금 다시 선정한 내용이 저장된 내용과 같으면 `true` |
| `ruleVersionChanged` | 브리프의 선정 규칙 버전이 현재 규칙과 다르면 `true`. 이때 `upToDate`는 항상 `false`다. |
| `evaluatedAt` | 확인을 시작한 UTC 시각. 마이크로초 정밀도다. |

## 판정 규칙

- 저장된 `weekStart`·`zoneId`로 [PRD-0024](../0024_baton-driven-edition-generation/spec.md) 생성과 같은
  주간 구간을 다시 계산한다. [PRD-0029](../0029_edition-carry-over/spec.md) 선정 규칙과 같은 함수로 현재 항목을
  선정·정렬하고, 저장된 항목 목록과 필드·순서까지 비교한다.
- 규칙 버전과 항목 목록이 모두 같으면 `upToDate=true`이고, 하나라도 다르면 `false`다.
- 내용 일치 판정이다. 최신 세대가 아닌 브리프도 내용이 같으면 `true`다. 지금 생성을 요청할 때 같은
  `editionId`를 재사용한다는 뜻은 아니며, 재사용 규칙은 PRD-0024를 따른다.
- BRIEF가 이미 수신한 이벤트까지만 반영한다. BATON에서 아직 전달되지 않은 변경과 outbox 대기·실패는
  알 수 없으므로 BATON의 추가 전달 안내를 대신하지 않고 함께 표시한다.
- 브리프·항목·현재 투영·수신 기록을 만들거나 바꾸지 않는다. 잠금 없이 한 번의 조회 결과로 판정한다.
- 응답은 확인 시점마다 달라질 수 있어 ETag를 제공하지 않는다. 서비스 Caddy가 `Cache-Control: no-store`를 붙인다.

## 서비스 경계

- 사용자 권한은 BATON이 판정한다. BRIEF는 경로 범위와 브리프 소속만 확인한다.
- 서비스 API 인증과 허용 경로는 [PRD-0025](../0025_baton-service-api-security/spec.md)를 따른다.
- 생성 시점·대상 결정, 스케줄러와 BATON 전달 기록 조회를 BRIEF에 추가하지 않는다.

## 제외 범위

- 다시 만들 때의 항목 차이 목록. 필요하면 생성한 뒤 PRD-0005·PRD-0032 비교를 사용한다.
- 여러 브리프의 일괄 확인과 이벤트 전달 완료 여부 판정

## 수용 기준

- 생성 직후에는 `upToDate=true`이고, 선정 범위 안의 활성 항목이 바뀌면 `false`다.
- 주간 종료 이후처럼 선정 범위 밖의 항목은 판정에 영향을 주지 않는다.
- 상태가 처음 선정 내용으로 돌아오면 최신 세대가 아니어도 `true`다.
- 이전 규칙 버전의 브리프는 항목이 같아도 `upToDate=false`, `ruleVersionChanged=true`다.
- 다른 범위나 없는 브리프는 `404`이며, 확인 전후 브리프 저장 상태가 바뀌지 않는다.
