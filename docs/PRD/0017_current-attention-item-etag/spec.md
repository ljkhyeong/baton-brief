# PRD-0017: 현재 관심 항목 조건부 조회

- 상태: 채택됨
- 결정일: 2026-08-22
- 범위: 현재 관심 항목 단건 응답의 `ETag`와 `If-None-Match` 조건부 조회

## 목적

PRD-0013의 현재 관심 항목 단건 조회는 호출자가 같은 복합 정체성의 최신 상태를 반복해서
확인할 수 있게 한다. 현재 응답은 마지막 적용 이벤트가 없더라도 전체 본문을 매번 반환한다.

현재 투영의 규칙 버전과 마지막 적용 집계 리비전을 HTTP 캐시 검증자에 결합해, 호출자가
이미 가진 현재 표현과 같으면 본문을 다시 전송하지 않게 한다. 투영 저장·조회 의미와 기존
응답 필드는 바꾸지 않는다.

## 적용 경로

다음 인증 없는 내부 로컬 MVP 경로에 강한 `ETag`를 포함한다.

| 메서드 | 경로 | 의미 |
|---|---|---|
| `GET` | `/api/v1/workspaces/{workspaceId}/seasons/{seasonId}/attention-items/current` | 정확한 복합 정체성의 현재 관심 항목 조건부 조회 |

기존 `200 OK`, 입력 오류 `400 ProblemDetail`과 미존재 `404 ProblemDetail` 의미를 유지한다.

## 검증자 의미

- 검증자는 API v1의 현재 관심 항목 표현, 적용한 `ruleVersion`과 마지막
  `aggregateRevision`에 결합한다.
- 현재 항목은 더 큰 집계 리비전의 지원 이벤트가 적용되거나 투영 규칙 버전이 바뀔 때만
  표현이 바뀐다. 두 값이 같으면 상태·심각도·관측 시각·누적 리비전 공백을 포함한 현재
  응답도 같다.
- `STALE`, `DUPLICATE`, `CONFLICT`, `UNSUPPORTED`는 현재 투영을 바꾸지 않으므로 검증자도
  바꾸지 않는다.
- 같은 규칙으로 성공한 전체 재구축은 현재 표현을 재현하므로 검증자를 바꾸지 않는다.
- 호출자는 검증자 내부 형식을 해석하지 않고 응답 값을 그대로 `If-None-Match`에 전달한다.
- 응답 표현 계약이 바뀌면 이전 표현과 같은 검증자를 재사용하지 않도록 표현 버전을 함께
  변경한다.

검증자는 해당 요청 URI에서 선택한 현재 항목만 검증한다. 다른 작업공간·시즌·이벤트
종류·원본 참조에 대한 전역 버전이나 목록 스냅샷 토큰이 아니다.

## 조건부 응답

- 현재 검증자와 일치하는 `If-None-Match`가 오면 `304 Not Modified`와 빈 본문을 반환한다.
- 검증자가 없거나 현재 값과 다르면 `200 OK`, 전체 현재 관심 항목 본문과 새 `ETag`를
  반환한다.
- 정확한 복합 정체성에 현재 항목이 없으면 조건부 헤더 유무와 관계없이 기존
  `404 ProblemDetail` 계약을 따른다.

Spring MVC가 `ResponseEntity`의 `ETag`를 사용해 표준 조건부 요청을 처리하게 한다. 직접
`If-None-Match`를 파싱하거나 `304` 응답을 조립하지 않는다.

## 영속성과 호환성

- 기존 `AttentionItem`의 `ruleVersion`과 `lastRevision`만 사용한다.
- 새 테이블, 열, 인덱스, Flyway 마이그레이션, 본문 해시와 캐시 저장소를 추가하지 않는다.
- 기존 `AttentionItemResponse` 필드와 단건 조회의 복합 정체성·상태 의미를 바꾸지 않는다.
- 현재 목록, 상태 전이 이력, 이벤트 수신 증거와 불변 에디션 응답에는 이 계약을 확대하지
  않는다.

## 수용 기준

- 현재 단건 조회의 `200 OK` 응답이 강한 `ETag`를 제공한다.
- 같은 현재 표현에 일치 검증자를 보내면 `304 Not Modified`와 빈 본문을 반환한다.
- 더 큰 리비전의 상태 전이가 적용되면 이전 검증자는 일치하지 않고 `200 OK`, 새 본문과
  다른 `ETag`를 반환한다.
- 성공한 재구축과 투영을 바꾸지 않는 수신 결과는 검증자를 바꾸지 않는다.
- 기존 입력 오류, 미존재, 응답 본문과 저장 상태가 유지된다.

## 명시적 비목표

- 현재 관심 항목 목록과 상태 전이 이력의 조건부 조회
- `Cache-Control` TTL, `Expires`, 브라우저·CDN·공유 캐시 운영 정책
- 직접 헤더 파서, 응답 본문 해시, 캐시 저장소와 무효화 작업
- 현재 항목 수정 명령, 과거 전체 투영 스냅샷과 목록 스냅샷 토큰
- 인증·인가, 외부 공개 API와 운영 배포
