# PRD-0017: 점검 항목 조건부 조회

- 상태: 채택됨
- 결정일: 2026-08-22
- 범위: 점검 항목 단건 응답의 `ETag`와 `If-None-Match` 조건부 조회

## 목적

점검 항목을 반복 조회할 때 내용이 같으면 본문을 다시 보내지 않는다.
규칙 버전과 마지막 적용 리비전으로 `ETag`를 만들고, 호출자가 보낸 `If-None-Match`와
일치하면 `304 Not Modified`를 반환한다. 저장·조회 규칙과 응답 필드는 유지한다.

## 적용 경로

다음 인증 없는 내부 로컬 MVP 경로에 강한 `ETag`를 포함한다.

| 메서드 | 경로 | 의미 |
|---|---|---|
| `GET` | `/api/v1/workspaces/{workspaceId}/seasons/{seasonId}/attention-items/current` | 정확한 복합 식별자의 점검 항목 조건부 조회 |

기존 `200 OK`, 입력 오류 `400 ProblemDetail`과 미존재 `404 ProblemDetail` 의미를 유지한다.

## ETag 기준

- `ETag`는 API 응답 형식 버전(v1), 적용한 `ruleVersion`과 마지막 `aggregateRevision`으로 만든다.
- 현재 항목은 더 큰 집계 리비전의 지원 이벤트가 적용되거나 투영 규칙 버전이 바뀔 때만
  내용이 바뀐다. 두 값이 같으면 상태·심각도·관측 시각·누적 리비전 공백을 포함한 현재
  응답도 같다.
- `STALE`, `DUPLICATE`, `CONFLICT`, `UNSUPPORTED`는 현재 항목을 바꾸지 않으므로 `ETag`도
  바꾸지 않는다.
- 같은 규칙으로 재구축하면 현재 항목을 재현하므로 `ETag`도 유지한다.
- 호출자는 `ETag` 내부 형식을 해석하지 않고 응답 값을 그대로 `If-None-Match`에 전달한다.
- 응답 형식이 바뀌면 `ETag`에 사용하는 응답 형식 버전도 변경한다.

`ETag`는 요청 URI로 지정한 항목에만 적용한다. 다른 작업공간·시즌·이벤트 종류·원본 참조의
항목이나 목록 전체의 변경 여부를 확인하는 데 쓰지 않는다.

## 조건부 응답

- 현재 `ETag`와 일치하는 `If-None-Match`가 오면 `304 Not Modified`와 빈 본문을 반환한다.
- `If-None-Match`가 없거나 현재 `ETag`와 다르면 `200 OK`, 전체 점검 항목 본문과 `ETag`를
  반환한다.
- 정확한 복합 식별자에 현재 항목이 없으면 조건부 헤더 유무와 관계없이 기존
  `404 ProblemDetail` 계약을 따른다.

Spring MVC가 `ResponseEntity`의 `ETag`를 사용해 표준 조건부 요청을 처리하게 한다. 직접
`If-None-Match`를 파싱하거나 `304` 응답을 조립하지 않는다.

## 영속성과 호환성

- 기존 `AttentionItem`의 `ruleVersion`과 `lastRevision`만 사용한다.
- 새 테이블, 열, 인덱스, Flyway 마이그레이션, 본문 해시와 캐시 저장소를 추가하지 않는다.
- 기존 `AttentionItemResponse` 필드와 단건 조회의 복합 식별자·상태 의미를 바꾸지 않는다.
- 현재 목록, 상태 전이 이력, 이벤트 수신 기록과 브리프 응답에는 이 계약을 확대하지
  않는다.

## 수용 기준

- 현재 단건 조회의 `200 OK` 응답이 강한 `ETag`를 제공한다.
- 내용이 바뀌지 않은 항목에 기존 `ETag`를 보내면 `304 Not Modified`와 빈 본문을 반환한다.
- 더 큰 리비전의 상태 변경이 적용되면 이전 `ETag`는 일치하지 않고 `200 OK`, 새 본문과
  다른 `ETag`를 반환한다.
- 성공한 재구축과 현재 항목을 바꾸지 않는 수신 결과는 `ETag`를 바꾸지 않는다.
- 기존 입력 오류, 미존재, 응답 본문과 저장 상태가 유지된다.

## 제외 범위

- 점검 항목 목록과 상태 전이 이력의 조건부 조회
- `Cache-Control` TTL, `Expires`, 브라우저·CDN·공유 캐시 운영 정책
- 직접 헤더 파서, 응답 본문 해시, 캐시 저장소와 무효화 작업
- 현재 항목 수정 명령, 과거 전체 투영 스냅샷과 목록 스냅샷 토큰
- 인증·인가, 외부 공개 API와 운영 배포
