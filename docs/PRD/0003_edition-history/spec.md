# PRD-0003: 불변 에디션 이력 조회

- 상태: 채택됨
- 결정일: 2026-08-14
- 범위: 작업공간·시즌별 불변 에디션 요약의 키셋 조회

## 목적

PRD-0002는 작업공간·시즌 전역 최신 에디션과 식별자를 이미 아는 단건 에디션 조회를
제공한다. 그러나 상태 변화마다 새 `generation`을 보존해도 과거 `editionId`를 별도로 알고
있지 않으면 이전 스냅샷을 발견할 수 없다.

BATON UI가 작업공간·시즌 범위에서 에디션 이력을 안정적으로 탐색하고 기존 단건 조회로
이어갈 수 있도록 요약 목록 API를 추가한다. 에디션 내용과 원본 권한 판정을 복제하지
않는다.

## HTTP API

다음 인증 없는 내부 로컬 MVP 경로를 추가한다.

| 메서드 | 경로 | 의미 |
|---|---|---|
| `GET` | `/api/v1/workspaces/{workspaceId}/seasons/{seasonId}/editions` | 에디션 요약 이력 조회 |

경로의 `workspaceId`와 `seasonId`는 UUID다. 호출 권한은 BRIEF가 판정하지 않으며 운영
외부 공개를 허용하는 계약이 아니다.

### 질의 매개변수

| 이름 | 필수 | 제약 | 의미 |
|---|---|---|---|
| `beforeGeneration` | 아니요 | 양수 | 이 세대보다 작은 에디션만 조회하는 배타적 키셋 |
| `limit` | 아니요 | `1..100`, 기본값 `20` | 한 응답에 포함할 최대 에디션 수 |

숫자로 변환할 수 없는 값과 범위를 벗어난 값은 `400 Bad Request`로 거부한다.

## 응답

성공 응답은 `200 OK`이며 다음 필드를 가진다.

- `editions`: `generation` 내림차순으로 정렬된 에디션 요약 배열
- `nextBeforeGeneration`: 다음 페이지가 있을 때 마지막으로 반환한 `generation`, 없으면
  `null`

각 요약은 다음 필드만 포함한다.

| 필드 | 의미 |
|---|---|
| `editionId` | 기존 단건 조회에 사용할 불변 에디션 식별자 |
| `generation` | 작업공간·시즌에서 증가하는 세대 |
| `weekStart` | 에디션 주간의 월요일 지역 날짜 |
| `zoneId` | 생성에 사용한 IANA 시간대 ID |
| `generatedAt` | 에디션 생성 시각 |
| `sourceCursor` | 생성 시 고정한 BRIEF 로컬 수신 기록 경계 |
| `ruleVersion` | 선정 규칙 버전 |
| `itemCount` | 에디션에 고정된 항목 수 |

고정 항목의 표시 필드와 구간 상세는 기존 `GET /api/v1/editions/{id}`에서 조회한다. 목록
응답에 전체 항목을 중복 포함하지 않는다.

## 페이지 의미

- 첫 요청에서 `beforeGeneration`을 생략하면 현재 최대 세대부터 조회한다.
- 다음 페이지는 직전 응답의 `nextBeforeGeneration`을 그대로 전달한다.
- `beforeGeneration`은 배타적이므로 페이지 사이에 같은 세대가 중복되지 않는다.
- 에디션과 세대는 불변이며 새 세대는 기존 최대값 뒤에만 추가되므로, 진행 중 새 에디션이
  생성되어도 이미 시작한 과거 방향 탐색에서 항목이 밀리거나 누락되지 않는다.
- 다음 페이지 존재 여부는 `limit`보다 한 건 더 조회해 판단하며 전체 개수 조회를
  수행하지 않는다.
- 해당 범위에 에디션이 없으면 `editions`는 빈 배열이고 `nextBeforeGeneration`은 `null`이다.

## 호환성과 비목표

- 기존 PRD-0002 API와 응답을 바꾸지 않는 추가 계약이다.
- 이벤트 v1, 투영 규칙, 에디션 생성·불변성·최신 선택 의미를 바꾸지 않는다.
- 전체 개수, offset 페이지네이션, 주간·시간대 필터와 정렬 선택지를 제공하지 않는다.
  PRD-0009의 정확한 작업공간·시즌·주간·시간대 최신 단건 조회는 별도 직접 조회이며 이력
  페이지의 필터나 정렬 선택지가 아니다.
- 에디션 항목 검색, 삭제, 보존 기간과 격리 운영 정책은 포함하지 않는다.
- BATON 멤버십, 인증·인가, 외부 시스템 연동과 운영 배포는 포함하지 않는다.

## 수용 기준

- 결과가 작업공간·시즌 범위를 벗어나지 않고 `generation` 내림차순으로 반환된다.
- `limit`을 넘지 않으며 `nextBeforeGeneration`을 사용한 다음 페이지에 중복이나 누락이
  없다.
- 각 요약의 `itemCount`가 저장된 불변 항목 수와 일치하고 `editionId`로 기존 단건 조회가
  가능하다.
- 빈 범위는 `200 OK`와 빈 배열을 반환한다.
- 잘못된 UUID, 양수가 아닌 `beforeGeneration`, `1..100` 밖의 `limit`은 `400 Bad Request`다.
