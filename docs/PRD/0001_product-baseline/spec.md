# PRD-0001: BATON BRIEF 제품 기준

- 상태: 초안
- 범위: 첫 독립 서비스 경계와 MVP

## 문제

BATON 생태계에는 역할 인수인계, 반복 운영, 결정과 자료 상태처럼 사용자가 주기적으로
확인해야 할 사실이 축적된다. 원본 화면을 모두 순회하는 대신, 특정 기간에 주의가 필요한
사실과 그 이유를 하나의 재현 가능한 운영 스냅샷으로 제공할 필요가 있다.

## 목표

- BATON이 발행한 운영 사실을 멱등하게 수신한다.
- 사람이 이해할 수 있는 이유와 원본 참조를 가진 관심 항목을 만든다.
- 작업공간·시즌 및 시간 구간별 불변 브리프 에디션을 생성한다.
- 같은 입력과 규칙 버전으로 같은 결과를 재현하고 전체 투영을 재구축할 수 있다.

## 비목표

- BATON의 운영 연속성 판단, 권한 또는 원본 도메인 상태 재구현
- WATCH 데이터베이스 직접 조회 또는 URL 상태 재판정
- RELAY의 구독, 제공자 호출, 재시도와 결과 관리
- GO의 공개 링크 생성·만료·폐기
- 자유 형식 AI 요약을 최종 판단 기준으로 사용
- 첫 MVP의 개인별 추천, 이메일 또는 메시지 발송

## 핵심 개념

### SourceEventReceipt

수신한 이벤트 식별자, 버전, 페이로드 지문, 수신·처리 상태와 실패 분류를 보존한다.
같은 식별자와 같은 페이로드의 재생은 기존 결과를 반환하고, 같은 식별자의 다른 페이로드는
충돌로 격리한다.

### AttentionItem

사용자가 주의를 기울여야 할 하나의 설명 가능한 투영이다. 최소한 다음 의미를 가진다.

- 작업공간과 시즌 참조
- 안정적인 `reasonCode`
- 제한된 `severity`
- 원본 종류와 불투명 원본 참조
- 원본이 관측한 시간과 BRIEF가 투영한 시간
- 적용한 규칙 버전
- 활성, 해소 또는 대체된 상태

### BriefEdition

하나의 작업공간·시즌, 시간대와 `[windowStart, windowEnd)`에 대해 생성한 불변 스냅샷이다.
생성 당시 포함한 관심 항목의 표시 필드를 고정하며 이후 원본 변경으로 기존 에디션을
덮어쓰지 않는다.

## 불변식

1. 한 이벤트 식별자는 하나의 페이로드 지문과만 결합한다.
2. 한 에디션 식별자는 하나의 작업공간·시즌, 구간과 규칙 버전을 가리킨다.
3. 생성 완료된 에디션의 항목과 구간은 수정하지 않는다.
4. BRIEF는 원본 엔티티의 존재를 외래 키나 공유 데이터베이스로 강제하지 않는다.
5. 권한과 멤버십의 최종 판단은 BATON이 수행한다.
6. 도착 순서만으로 최신 원본 상태를 결정하지 않는다.

## 목표 사용자 흐름

1. BATON이 도메인 변경과 같은 트랜잭션에 아웃박스 레코드를 저장한다.
2. 커밋 이후 발행기가 버전이 있는 이벤트를 BRIEF에 최소 한 번 전달한다.
3. BRIEF가 수신 기록을 원자적으로 저장하고 관심 항목 투영을 갱신한다.
4. 로컬 MVP에서는 명시적 HTTP 명령이 시즌 시간대 기준 주간 에디션을 생성한다.
5. BATON UI가 권한을 확인한 뒤 최신 또는 특정 에디션을 조회해 표시한다.

PRD-0002의 로컬 MVP는 BRIEF 내부 HTTP 엔드포인트까지만 구현한다. 위 흐름의 BATON 아웃박스,
발행기와 UI 변경은 이번 구현 범위가 아니다.

## MVP 수용 기준

- 완전히 같은 이벤트의 재생이 중복 관심 항목이나 에디션을 만들지 않는다.
- 같은 이벤트 식별자의 다른 페이로드가 정상 이벤트를 덮어쓰지 않는다.
- 순서가 뒤바뀐 이벤트와 투영 재구축을 테스트로 검증한다.
- 에디션 구간 경계와 일광 절약 시간 전환을 고정 시각 테스트로 검증한다.
- 모든 표시 항목에 안정적인 이유 코드와 원본 참조가 있다.
- BRIEF 장애가 BATON의 원본 변경을 롤백하지 않는다.
- 제공자, 자격 증명, 원문 비밀 값과 불필요한 PII를 저장하거나 로그에 남기지 않는다.

## 후속 결정 사항

- 보존 기간, 격리 운영과 재구축 SLO
- 운영 전송 방식과 BATON 조회 인증 방식
- RELAY와 GO를 연결할 후속 참조 계약

첫 MVP의 내부 HTTP 경로, 이벤트 v1 봉투와 이벤트 목록, 투영 규칙, 재구축과 주간
에디션 계약은 PRD-0002에서 채택한다.
