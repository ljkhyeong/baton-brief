# PRD-0009: 주간 범위 최신 불변 에디션 조회

- 상태: 채택됨
- 결정일: 2026-08-20
- 범위: 작업공간·시즌·주간·시간대 정확 범위의 최신 불변 에디션 단건 조회

## 목적

PRD-0002의 기존 최신 조회는 작업공간·시즌 전체에서 가장 큰 `generation`을 반환한다.
서로 다른 주간의 에디션이 같은 세대 순서를 공유하므로, 이 전역 포인터만으로는 BATON UI가
선택한 주간의 최신 스냅샷을 직접 찾을 수 없다.

기존 전역 최신 의미를 바꾸지 않고 작업공간, 시즌, `weekStart`와 `zoneId`가 정확히 같은
범위에서 가장 큰 `generation`의 저장된 불변 에디션을 조회하는 별도 내부 API를 추가한다.

## HTTP API

다음 인증 없는 내부 로컬 MVP 경로를 추가한다.

| 메서드 | 경로 | 의미 |
|---|---|---|
| `GET` | `/api/v1/workspaces/{workspaceId}/seasons/{seasonId}/editions/weekly/latest` | 지정한 주간 범위의 최신 완료 에디션 조회 |

경로의 `workspaceId`와 `seasonId`는 UUID다. 호출 권한은 BRIEF가 판정하지 않으며 외부
공개나 운영 사용을 허용하는 계약이 아니다.

### 질의 매개변수

| 이름 | 필수 | 형식과 제약 | 의미 |
|---|---|---|---|
| `weekStart` | 예 | ISO-8601 지역 날짜 문자열, 반드시 월요일 | 조회할 주간의 지역 날짜 시작 |
| `zoneId` | 예 | JVM이 제공하는 이름 있는 IANA 시간대 ID | 에디션 생성에 사용한 시간대 |

`+09:00` 같은 고정 오프셋은 `zoneId`로 받지 않는다. 잘못된 날짜, 월요일이 아닌 날짜,
고정 오프셋 또는 알 수 없는 시간대는 `400 Bad Request`와 PRD-0004의 표준
`ProblemDetail`로 거부한다.

## 선택과 응답 의미

- 조회 범위는 `(workspaceId, seasonId, weekStart, zoneId)`가 모두 정확히 같은 저장
  에디션이다.
- 해당 범위에서 `generation`이 가장 큰 완료 에디션 한 건을 선택한다. `generation`은
  계속 작업공간·시즌 전체에서 증가하며 주간별로 다시 시작하지 않는다.
- `ruleVersion`은 질의 필터가 아니다. 서로 다른 규칙 버전의 에디션이 같은 주간 범위에
  있으면 가장 큰 `generation`을 선택하고, 실제 저장된 `ruleVersion`을 응답에 포함한다.
- 응답은 PRD-0002의 기존 에디션 본문과 같은 저장된 전체 불변 스냅샷이다. 현재
  `AttentionItem` 투영을 다시 조합하거나 기존 에디션의 항목·구간·커서를 변경하지 않는다.
- PRD-0012에 따라 선택된 에디션의 `ETag`를 제공하며, 같은 검증자를 보낸
  `If-None-Match` 요청은 `304 Not Modified`를 반환한다.
- 정확한 범위에 에디션이 없으면 `404 Not Found`와 PRD-0004의 표준 `ProblemDetail`을
  반환한다.

기존 `GET /api/v1/workspaces/{workspaceId}/seasons/{seasonId}/editions/latest`는 계속
작업공간·시즌 전체에서 가장 큰 `generation`을 반환한다. 주간 조회 추가로 기존 경로의
의미나 응답을 바꾸지 않는다.

## 영속성과 호환성

- 기존 `brief_edition`과 불변 항목을 읽으며 새 테이블, 열, 마이그레이션 또는 에디션
  모델을 추가하지 않는다.
- 읽기 전용 조회이므로 에디션 생성, 현재 투영, 수신 기록과 재구축 상태를 변경하지 않는다.
- PRD-0003의 이력 API에 주간·시간대 필터를 추가하지 않는다. 이 API는 정확한 주간 범위의
  단건 직접 조회이며, 이력 페이지네이션이나 전체 개수 조회가 아니다.
- 규칙 버전을 질의 조건으로 추가하거나 전역 최신 조회를 주간 최신 조회로 재해석하지
  않는다.
- BATON 생산자 변경, 스케줄러, 브로커, 인증·인가, 외부 시스템 연동과 운영 배포는
  포함하지 않는다.

## 수용 기준

- 전역 최신과 주간 최신이 서로 다른 에디션인 데이터에서 각 경로가 자신의 범위에 맞는
  최대 `generation`을 반환한다.
- 같은 주간·시간대에서 새 세대가 생기면 주간 최신 조회가 그 저장 스냅샷을 반환하고
  이전 에디션은 변하지 않는다.
- 다른 작업공간, 시즌, 주간 또는 시간대의 에디션이 결과에 섞이지 않는다.
- 저장 뒤 현재 투영이나 재구축 결과가 달라져도 반환하는 에디션 내용은 변하지 않는다.
- 정확한 범위가 없으면 `404 Not Found`를 반환한다.
- 월요일이 아닌 `weekStart`와 이름 있는 IANA ID가 아닌 `zoneId`는 `400 Bad Request`다.

## 명시적 비목표

- 이력 목록의 주간·시간대 필터와 offset 페이지네이션
- 규칙 버전별 최신 조회
- 현재 투영에서 에디션을 즉석 생성하거나 재조합하는 조회
- 에디션 스키마, 생성 규칙, `generation` 할당과 보존 정책 변경
- 운영 인증·인가와 외부 공개 API
